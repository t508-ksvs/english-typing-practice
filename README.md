# 英文打字格式練習 (English Typing Practice) - 技高專案升級版

> 高雄高工 (Kaohsiung Industrial High School) 英語科教學團隊  
> 專為技高（高職）學生打造的英文打字格式防呆闖關系統

## 專案特色
- **免安裝、跨載具**：iPad、Android 平板、Windows 小電腦或手機開啟瀏覽器即可直接練習。
- **6 大漸進式情境關卡**：
  - Level 1: Expressing Likes (生活基礎句型)
  - Level 2: Making an Invitation (社交對話問句)
  - Level 3: Complex Sentence (標點防呆與縮寫)
  - Level 4: Automotive / Tool Scenario (汽車修護步驟情境)
  - Level 5: Machinery / Factory Safety (工場機台工安對白)
  - Level 6: Video Project Script (完整分鏡劇本角色台詞)
- **即時全形字元偵測**：誤打全形字母或全形標點立即跳出標紅警示。
- **標點空格智能校對**：即時比對「標點貼前字、標點後空一格」。
- **防偽通關證書卡**：通關後自動生成彩帶特效與專屬完成證明卡（含自訂姓名座號與隨機防偽驗證碼），方便學生截圖繳交至 Google Classroom。
